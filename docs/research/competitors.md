# Competitive Analysis

## Goal

Understand existing NFT whitelist tools and identify gaps our product can solve.

## Competitors

### Premint

Focus:
- WL registration
- Project management
- Anti-bot verification

Weakness:
- Not a universal WL eligibility checker.

### Atlas3

Focus:
- Raffles
- Discord verification
- Community campaigns

Weakness:
- Requires project integration.

### Alphabot

Focus:
- Raffles
- Reputation
- Anti-bot systems

Weakness:
- Primarily project-integrated and heavily off-chain.

### Ouellette

Focus:
- NFT mint calendar
- WL discovery

Weakness:
- Does not actually verify wallet eligibility.

### GoldRush

Focus:
- Blockchain data APIs
- NFT ownership
- Wallet history

Weakness:
- Infrastructure rather than a consumer WL checker.

### Magic Eden

Focus:
- Solana marketplace
- Launchpad
- NFT mints

Weakness:
- Ecosystem/platform-specific.

## Competitive Gap

Existing products generally solve one of these problems:

1. WL registration
2. WL distribution
3. Mint discovery
4. Blockchain data
5. Project-specific eligibility

Our product combines the missing layer:

**Cross-chain wallet → eligibility discovery → verification**

## Product Differentiation

The system should provide:

- Multi-chain support
- One wallet check
- Multiple projects
- Multiple eligibility mechanisms
- Read-only verification
- Verification confidence
- Data freshness indicators
- Security warnings
- Extensible architecture

## Initial Chains

1. Ethereum
2. Base
3. Solana
4. Robinhood Chain

The architecture should allow additional chains later.
